首次下载版面模型、字体等资源；以后换论文直接复用，不调用翻译 API。

先运行随插件提供的 setup.ps1（Windows）或 setup.sh，将脚本输出的 Python 路径填入。

Codex 模型

切换到 Codex 后，读取当前登录账户的模型列表。

推理强度

列表来自当前官方 Codex CLI；切换账户或更新 CLI 后可刷新。仅显示所选模型支持的推理强度。论文翻译可从 low 开始，难句较多可试 medium；更高强度通常更慢、消耗更多额度，也不能修复 PDF 排版。

默认同时处理 2 批，减少逐批等待；网络或账户限流时可改为 1。并行不表示额度免费或保证按倍数加速。

先在官方 Codex CLI 运行 codex login，用 ChatGPT 账户登录。后台使用临时会话，不保存本地聊天记录；仍消耗 Codex 额度，论文文本会发送给 OpenAI，不代表服务端零留存。额度不足会停止，不会自动回退到 API。关闭自动术语提取以减少额外调用。

密钥保存在 Zotero 的密码管理器。更换接口地址后，会读取该地址对应的密钥。

翻译选项

每秒请求数用于 API 方式。

每次点击“翻译”时单独填写页码，留空翻译全文。

个别段落翻译失败时保留原文，仍保存两份 PDF；附件标题、备注和 PDF 批注会提示未译内容。

BabelDOC 在本机解析和排版；待翻译文本发送到上方模型接口。首次运行可能联网下载版面模型和字体。本机模型与所需资源齐备后可离线运行。
